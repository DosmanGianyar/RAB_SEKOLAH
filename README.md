# E-RAB SEKOLAH

Sistem Informasi Pengajuan Anggaran, Otorisasi Bertingkat, Pencairan Dana, dan LPJ Internal Berbasis Web Praktis.

---

## Panduan Cepat Menjalankan Sistem

1. **Clone Repositori:**
   ```bash
   git clone https://github.com/DosmanGianyar/RAB_SEKOLAH.git
   cd RAB_SEKOLAH
   ```

2. **Pasang Dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Aplikasi:**
   ```bash
   npm start
   ```
   Buka di browser: **[http://localhost:3000](http://localhost:3000)**
